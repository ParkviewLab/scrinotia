# Security

Please report a security problem privately, not in a public issue: use [Report a vulnerability](https://github.com/ParkviewLab/scrinotia/security/advisories/new) on the repository's Security tab. The report is seen only by the maintainer.

Fixes are made in the newest release only. Scrinotia keeps all data on your own machine and reaches the network only for images a note links from the web and for the update check in the About window (requirement R6.3 in [`docs/requirements.md`](docs/requirements.md)), so reports about those, about opening a vault, and about the sandbox for HTML attachments are the most useful.
