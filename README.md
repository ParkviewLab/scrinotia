# granite-vaulting

An independent, local-first Markdown notes client for macOS and Ubuntu. It opens a vault (a folder of Markdown notes) without altering it, and offers a live-preview editor, wikilinks with backlinks, and search.

Status: requirements stage. Nothing is built yet; the requirements are in [`docs/requirements.md`](docs/requirements.md).

The client is built with Electron and CodeMirror 6, and is licensed under AGPL-3.0-or-later (see [`LICENSING.md`](LICENSING.md)).
